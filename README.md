# Monitor de Queimadas Chapada Diamantina 🌄

Esse projeto busca monitorar incendios na região da Chapada Diamantina, 
utilizando dados de satélite e técnicas de análise geoespacial 
para identificar áreas de risco e fornecer informações em tempo real sobre queimadas. 
O objetivo é apoiar ações de prevenção e combate a incêndios, 
contribuindo para a preservação do meio ambiente e a segurança das comunidades locais.

---

### Funcionalidades

- Coleta de dados de satélite sobre possiveis queimadas na região da Chapada Diamantina
- Análise geoespacial para identificar áreas de risco.
- Coleta de temperatura e umidade do ar para auxiliar na previsão de incêndios.
- Visualização de informações em tempo real sobre queimadas
- Alertas e notificações sobre incêndios em andamento

---
### Tecnologias Utilizadas

- Python
- Bibliotecas de análise geoespacial (Geopandas)
- APIs de dados de satélite (NASA FIRMS)
- Banco de dados para armazenamento de informações (PostgreSQL)
- Frameworks de visualização.
- Obtenção de dados meteorológicos.
- Oracle Cloud Infrastructure para hospedagem e processamento de dados.
